# Security

**A problem in this bridge:** please use a [private vulnerability report](../../security/advisories/new) instead of a public issue.

**A problem in Parro itself:** report it to Topicus directly through their [responsible disclosure policy](https://www.parnassys.nl/juridisch/disclaimer), not here.

Never put tokens, passwords, real messages, or names of parents and children in an issue, log excerpt or screenshot.
